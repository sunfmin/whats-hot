# whats-hot

whats-hot is superseded by [hostvitals](https://github.com/sunfmin/hostvitals).

Install the CLI and its skill:

```sh
brew install sunfmin/tap/hostvitals
npx skills add sunfmin/hostvitals
```

Start with `hostvitals --help` and follow its help for the requested observation.

The [skill](skills/whats-hot/SKILL.md) is a pointer to hostvitals. The
[ADRs](skills/whats-hot/docs/adr) preserve the design decisions, including the
[replacement mapping](skills/whats-hot/docs/adr/0005-superseded-by-hostvitals.md).
